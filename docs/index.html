Guides pas à pas

Touchez un guide pour le déplier. Tout est expliqué, même si vous débutez.

1. Installer l'application sur Android
  1. Sur votre téléphone, touchez le bouton Télécharger l'application (APK) de cette page.
  2. Si Chrome affiche « Ce type de fichier peut être dangereux », touchez Télécharger quand même. C'est un avertissement automatique pour tout fichier APK hors Play Store.
  3. Ouvrez le fichier téléchargé (notification, ou dossier « Téléchargements »).
  4. Android demande d'autoriser l'installation depuis votre navigateur : touchez Paramètres, activez Autoriser depuis cette source, puis revenez en arrière.
  5. Touchez Installer, puis Ouvrir.
Si « Play Protect » affiche « Application inconnue » : touchez Plus de détails, puis Installer quand même. L'application n'est simplement pas distribuée via le Play Store.

Une fois l'installation terminée, vous pouvez retirer l'autorisation donnée au navigateur dans les paramètres Android.

2. Créer votre compte et démarrer l'essai de 45 jours
  1. Ouvrez l'application et choisissez de créer un compte.
  2. Saisissez votre adresse e-mail et un mot de passe.
  3. Votre période d'essai gratuite de 45 jours démarre immédiatement, avec toutes les fonctions.

Vous pouvez suivre le temps restant depuis l'onglet Compte. Vous êtes prévenu avant la fin de l'essai.

3. Créer une clé API SANS droit de retrait (très important)

La clé API est ce qui permet à l'application de passer des ordres sur votre compte. Elle doit toujours être créée sans le droit de retrait.

Bybit

  1. Mode Démo : bybit.com, profil, « Demo Trading », puis API.
  2. Mode Réel : profil, API, nouvelle clé.
  3. Droits : Lecture-Écriture, limités aux contrats. Ne cochez jamais « Retrait ».

Binance Futures

  1. Mode Démo : utilisez les clés de l'environnement de test Binance Futures (Demo Trading).
  2. Mode Réel : Gestion API, créez une clé, activez Futures. Ne cochez jamais les retraits.
  3. Mettez votre compte en mode One-way (position unique).

Kraken Futures (bêta)

  1. Mode Démo : demo-futures.kraken.com, Paramètres, API.
  2. Mode Réel : futures.kraken.com, Paramètres, Clés API, avec droits de trading uniquement, sans retrait.
Conseil sécurité : si votre exchange le permet, limitez la clé à l'adresse IP de votre connexion et ne la partagez avec personne, pas même avec nous.

Ensuite, dans l'application : onglet Compte, choisissez l'exchange, collez la clé et le secret, puis lancez le test de connexion.

4. Bien débuter : Simulation, Démo, puis Réel
  • Simulation : argent fictif, aucun compte d'exchange requis. Idéal pour comprendre les réglages et le tableau de bord.
  • Démo : l'environnement de test de votre exchange. Les ordres sont réels sur un compte fictif, ce qui valide votre connexion API.
  • Réel : votre vrai compte. Commencez avec un petit montant que vous pouvez vous permettre de perdre.

Avant de passer en réel, lancez un backtest sur la paire et la période qui vous intéressent, puis laissez tourner la démo plusieurs jours.

Règle d'or : ne passez en réel que si vous comprenez pourquoi le bot prend ses positions et combien vous pouvez perdre au maximum.
5. Régler le risque et les protections
  • Définissez la part du capital engagée par position.
  • Activez les protections de risque proposées dans les réglages avancés.
  • Utilisez le bouton d'arrêt à tout moment pour couper le bot.

Un réglage prudent vaut mieux qu'un réglage agressif : le scalping avec effet de levier amplifie les gains comme les pertes.

6. Recevoir les alertes Telegram
  1. Dans Telegram, cherchez @BotFather, envoyez /newbot et suivez les étapes. Vous recevez un token.
  2. Envoyez un message à votre nouveau bot.
  3. Ouvrez dans votre navigateur https://api.telegram.org/bot suivi de votre token puis /getUpdates. Repérez le nombre après "chat":{"id": : c'est votre chat id.
  4. Dans l'application, collez le token et le chat id, puis touchez le bouton de test.
7. Garder le bot actif en arrière-plan
  • Acceptez les notifications : le bot affiche une notification permanente pour rester actif.
  • Autorisez l'application à fonctionner sans restriction de batterie quand Android le propose.
  • Gardez une connexion Internet stable (Wi-Fi ou données mobiles).
  • Sur certains téléphones (Xiaomi, Huawei, Oppo…), activez aussi le « démarrage automatique » de l'application dans les paramètres du fabricant.
8. Recharger des TeraCoin après l'essai
  1. Dans l'application, ouvrez Compte > Mes TeraCoin.
  2. Saisissez le montant voulu : l'application affiche aussitôt le nombre de TeraCoin et de jours obtenus.
  3. Envoyez ce montant en USDT sur le réseau Polygon ou BNB Smart Chain (BEP-20) à l'adresse affichée dans l'application (copiez-la depuis l'application, jamais depuis un message reçu). C'est la même adresse sur les deux réseaux.
  4. Copiez le hash de la transaction (TxID) depuis votre portefeuille ou votre exchange, puis collez-le dans l'application.
  5. Vous pouvez aussi payer par Binance Pay : l'administrateur valide à la main, comptez quelques heures.
Attention : seul l'USDT sur Polygon ou BNB Smart Chain est accepté. Un envoi sur un autre réseau ou avec un autre jeton (BNB, BUSD, USDC…) peut être perdu.

Questions fréquentes

L'application peut-elle retirer mon argent ?

Non, à condition de créer votre clé API sans droit de retrait, comme expliqué dans le guide 3. Sans ce droit, aucune application ne peut retirer vos fonds avec cette clé.

Où sont stockées mes clés API ?

Sur votre téléphone, dans l'espace privé de l'application. Elles sont utilisées pour communiquer avec votre exchange.

Est-ce que l'application gagne de l'argent à coup sûr ?

Non. Aucun outil de trading ne peut garantir des gains. L'application vous donne des outils (backtest, simulation, démo, gestion du risque) pour décider en connaissance de cause.

Pourquoi l'application n'est-elle pas sur le Play Store ?

Elle est distribuée directement en fichier APK. C'est pourquoi Android demande une autorisation d'installation une seule fois.

L'application se met-elle à jour toute seule ?

Elle vous prévient au démarrage quand une nouvelle version existe et vous propose de la télécharger.

Que se passe-t-il à la fin de l'essai ?

Vous êtes prévenu avant la fin. Sans TeraCoin, l'accès aux fonctions se termine. Vos fonds ne sont jamais concernés : ils restent sur votre exchange.

Et sur iPhone ?

Pour l'instant, seule la version Android est distribuée.

Quels exchanges sont compatibles ?

Bybit, Binance Futures et Kraken Futures (support en bêta). Une simulation sans exchange est aussi disponible.
